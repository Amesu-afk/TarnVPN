# Как участвовать

Спасибо, что дошёл сюда. Правила короткие.

## Вопросы и обсуждения

Не баг и не запрос фичи? Задай вопрос в
[Discussions](https://github.com/Amesu-afk/TarnVPN/discussions) — там же идеи и
показ своих конфигураций. В issues место только для воспроизводимых проблем.

## Баги

Открывай issue по шаблону: версия приложения и код, Android и устройство, шаги,
ожидаемое/фактическое. Логи и конфиг — **без кредов**: вырежи ссылки подписок,
UUID, ключи, пароли и IP серверов.

## Уязвимости

Не открывай публичный issue. Порядок — в [SECURITY.md](SECURITY.md): приватный
GitHub Advisory.

## Pull requests

- Ветка от `tarnvpn`; один PR — одна тема.
- CI должен быть зелёным: gitleaks, сборка ядра из тега и unit-тесты
  (`.github/workflows/ci.yml`).
- Не коммить сборки, `libbox*.aar`, `local.properties`, keystore, HAR и логи —
  список в [docs/maintainer-checklist.md](docs/maintainer-checklist.md).
- Коммиты и код — по-английски, в стиле репозитория; комментарии объясняют
  «почему», а не «что».
- Влитие — squash: история релизов остаётся по одному коммиту на выпуск.
- Меняешь генератор конфига — подними `VlessImporter.CONFIG_GENERATION`, иначе
  правка не дойдёт до уже добавленных профилей.
