Относительно **v1.14.1**. Главное — добавление серверов из файла и починка импорта «неудобных» подписок (#14).

## Добавление конфига из файла

- В диалоге «Добавить сервер» рядом с QR появилась кнопка **папки**: системный файловый пикер открывает конфиг с устройства — список ссылок (vless, trojan, ss, vmess, hysteria2, tuic, anytls, olcRTC), base64-дамп подписки или WireGuard/AmneziaWG `.conf`/`vpn://`.
- Файл импортируется **группой** (как подписка): на экране «Подписки» её видно по имени файла и можно **удалить целиком** одной кнопкой. Повторный выбор того же файла обновляет группу на месте.

## Импорт подписок: что чинили (по issue #14)

- **Большие подписки больше не отбиваются лимитом.** Подписка на 1.5 МБ с тысячами серверов импортируется первыми 128 серверами с честным уведомлением «пропущено N из M»; лимит объёма поднят до 8 МиБ.
- **Plain-формат `ss://метод:пароль@host`** больше не даёт «unknown method»: парсер отличает его от base64 (SIP002) и не скармливает ядру мусор в поле шифра.
- **Многострочный файл, начинающийся с `vless://`,** больше не считается одной ссылкой — добавляются все серверы из файла, а не только первый.
- **base64 со стандартным «+»** больше не портится URL-safe декодером (было: «vmess payload is not JSON»).
- **`packetEncoding=none` из ссылок** больше не ломает профиль («unknown packet encoding»): отсутствие поля — тот же смысл.
- **Неизвестные uTLS-отпечатки** (`fp=unsafe` из Xray, опечатки провайдера) больше не убивают профиль — такое рукопожатие не маскируется; известные отпечатки (chrome, firefox…) работают как раньше.

## English

Adds config-file import to the servers screen: a system file picker (next to the QR button) reads a link list, base64 subscription dump or WireGuard/AmneziaWG .conf, grouped like a subscription — visible and deletable in one action on the subscriptions screen, and refreshed in place when the same file is picked again. Subscription import fixes (#14): oversized subscriptions import their first 128 servers instead of failing; legacy plain `ss://method:password@host` links no longer produce "unknown method"; a multi-line file starting with `vless://` imports all its servers; standard-alphabet base64 with '+' is no longer corrupted by the URL-safe decoder; `packetEncoding=none` and unknown uTLS fingerprints (`fp=unsafe`) no longer reject the profile. Core: tagged v1.14.4-lx.34 (Go 1.26.11), CI-verified inside the AAR.
