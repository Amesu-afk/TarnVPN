# TarnVPN 1.14.0-alpha.70

Предварительная версия для Android. Включает ранее подготовленные исправления alpha.69 и изменения надёжности после alpha.68.

## Что изменилось

- При удалении выбранного сервера или его подписки приложение запрашивает отключение VPN и снимает выбор. Если обновление подписки удалило бы выбранный сервер, оно останавливается; при ручном обновлении показывается сообщение.
- Исправлены сохранение уровня журнала Trace, отображение DNS в режиме Auto и отключение record fragmentation вместе с основной фрагментацией.
- В резервное копирование и перенос устройства не включаются временные копии файла подписок и каталоги crash/OOM-отчётов.
- Проверка серверов выполняется не более чем 12 соединениями одновременно; результаты отображаются одной группой. Улучшены потокобезопасность обновления профилей и отмена полного теста. Ошибка чтения конфига при перезагрузке сервиса обрабатывается.
- Включены подготовленные для alpha.69 изменения подключения olcRTC через Jitsi и Телемост: ожидание готовности канала и восстановление после потерь RTP. Формат существующих профилей сохранён.

## Установка и ограничения

Выберите universal APK для Android 6+ или legacy universal для Android 5. Для обновления из приложения выберите канал **«Бета»**. Нужен свой сервер или подписка.

Локально прошли 135 основных и 122 legacy unit-теста, обе release-сборки и lintVital. Подписи APK совпадают с alpha.68; встроенные библиотеки совпадают с alpha.69 для всех четырёх архитектур в обеих версиях.

Это предварительная сборка. Физическая проверка alpha.70, обновления поверх установленной версии, Android 5, сна и смены сети не проводилась. Предыдущая alpha.69 проверялась пользователем на Android с существующими профилями Jitsi и Телемоста; это не заменяет проверку новой версии.

Crash/OOM-отчёты всё ещё могут содержать конфигурацию с секретами во внешнем каталоге приложения: исключение из backup не устраняет этот риск. Массовое удаление серверов при частичном, но полностью валидном ответе подписки пока не защищено порогом. Не все случаи отмены полного теста устранены.

## English

Prerelease containing profile deletion safeguards, DNS and fragmentation setting fixes, subscription backup exclusions, bounded TCP probes, and the previously prepared olcRTC Jitsi/Telemost startup fixes. Select the Beta update channel. Physical-device validation of alpha.70 is pending. Crash/OOM reports can still contain sensitive configuration in external app storage.
