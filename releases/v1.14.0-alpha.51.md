## Что исправлено

- Обновление приложения: APK проверяется перед установкой — приложение, версия и подпись должны совпадать с ожидаемыми. Исправлены выбор совместимой сборки и повторное использование скачанного файла.
- Загрузка подписок и обновлений: добавлены ограничения времени, размера ответа и переходов по ссылкам. Незавершённая загрузка больше не принимается за готовый файл.
- Обновление подписки: изменения профилей записываются одной транзакцией базы данных, а при ошибке записи приложение пытается восстановить прежние файлы. Исправлена ситуация, когда запоздавший ответ возвращал уже удалённую подписку.
- Адреса подписок исключены из системной резервной копии. Повреждённый список подписок больше не подменяется пустым.
- XHTTP: исправлена гонка отмены подключения; таймаут нового запроса больше не закрывает общее соединение, если по нему недавно поступали данные.
- Диагностический архив, созданный через root, получает ограниченные права доступа.

- `TarnVPN-1.14.0-alpha.51-legacy-android-5-universal.apk` — Android 5.

Версия приложения: `1.14.0-alpha.51`, код `703`. Выпуск остаётся предварительным (alpha).

## Ограничения проверки

Проверка на физическом устройстве, установка поверх предыдущей версии и замеры XHTTP на реальном сервере не выполнены. Полное восстановление подписки после принудительного завершения процесса между записью файлов и базы данных пока не гарантируется.

Исходники Android соответствуют тегу этого релиза. Ядро основано на собственной ветке sing-box-lx; обновления upstream lx.29/lx.30 в этот выпуск не переносились.
