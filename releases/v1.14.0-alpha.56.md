# TarnVPN 1.14.0-alpha.56

Починено подключение к olcRTC-серверам на self-hosted Jitsi.

## Что изменено

- сигнальный трафик Jitsi (`/config.js`, XMPP WebSocket, colibri-ws) теперь идёт
  через сокеты, защищённые `VpnService.protect()`; раньше движок отдавал
  библиотеке `j` клиент по умолчанию, и запросы заворачивались в собственный
  туннель;
- из-за этого не читался `/config.js`, XMPP-домен молча откатывался на
  веб-хост и Prosody отвечал `host-unknown` («This server does not serve …»)
  на любом docker-jitsi-meet, где виртуалхост — `meet.jitsi`;
- добавлена предварительная загрузка `/config.js`: недоступный хост теперь
  сообщается как недоступный хост, а не как чужой домен;
- для профилей с `insecure` сохранён пропуск проверки сертификата;
- APK-код увеличен до 708 для обновления поверх alpha.55.

## Проверка

- сборка и unit-тесты `internal/engine/jitsi` и `internal/protect` проходят;
- живое подключение проверяется на устройстве.
