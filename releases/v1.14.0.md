# TarnVPN 1.14.0

Первый стабильный выпуск линии 1.14.0 после alpha.96. База — alpha.96 (watchdog, Always-on,
приватность); сверху — карта локации, определение страны по IP и очищенные настройки.

## Что нового

- **Карта на главном экране.** При подключении появляется карта мира в фирменной точечной
  графике, а точка стоит на стране выбранного сервера. Панель и рамка убраны — карта лежит
  прямо на фоне экрана. Кольца вокруг точки пульсируют.
- **Страна по IP, а не только по названию.** Приложение резолвит адрес выбранного сервера
  и ищет страну в офлайн-базе DB-IP Lite, встроенной в APK. IP никуда не отправляется,
  геосервисы не вызываются. Если имя профиля и адрес расходятся, карта показывает страну
  по IP и подпись «по IP · в имени: Германия». Если IP определить не удалось — запасной
  вариант по имени/городу.
- **Флаги и города в названиях.** Флаг-эмодзи и около 280 городов хостинга (Miami,
  Amsterdam, Frankfurt…) распознаются как подсказка, когда IP недоступен.
- **Настройки.** Экран «Защита» переименован в «Настройки». У большинства переключателей
  убраны длинные описания; короткие подсказки остались у IPv6, фрагментации TLS и split
  tunneling. «Постоянный VPN в системе» теперь ведёт в настройки Android короткой строкой.
- **Экран «Отключено».** Кнопка и карточка сервера больше не прилипают к строке статуса;
  свободное место в середине сохраняется и при выключенном туннеле.

## Обновление

`1.14.0` — стабильный канал. Обновление предлагается с alpha.96 (versionCode 757 → 758).
APK подписан тем же ключом: установка поверх предыдущей версии сохраняет профили и настройки.

## Ограничения

- Страна по IP — это страна регистрации входного адреса. Для CDN/domain fronting или
  anycast трафик может выходить в другой стране; офлайн-база этого не видит.
- IPv6-only серверы пока не покрыты базой и откатываются на определение по имени.
- В списке серверов флаг по-прежнему берётся из имени; карта на главном экране — из IP.
- База геоданных: DB-IP Lite, CC BY 4.0, снимок 2026-11. Атрибуция видна в «Настройках».

## English

First stable release of the 1.14.0 line after alpha.96. The core is unchanged from alpha.96.

- A world map now appears on the home screen while connected, with a pin on the server's
  country. No card or frame around it; the pin pulses.
- The country is resolved from the selected server's IP using the bundled DB-IP Lite table.
  No IP leaves the device and no geolocation service is called. When the profile name and
  the address disagree, the map shows the IP country and notes the name; a failed lookup
  falls back to the name/city.
- Flag emoji and roughly 280 hosting cities in profile names are understood as fallbacks.
- The settings screen is now titled Settings; long toggle descriptions are gone, with short
  hints kept for IPv6, TLS fragmentation and split tunneling.
- The disconnected layout no longer collapses to the top.

Limitations: the IP country is the registration country of the entry address, so CDN,
domain-fronting and anycast relays can be registered elsewhere. IPv6-only hosts fall back to
name detection. The server list keeps name-based flags; the home map uses the IP.

Geodata: DB-IP Lite, CC BY 4.0, 2026-11 snapshot. The attribution is shown in Settings.
