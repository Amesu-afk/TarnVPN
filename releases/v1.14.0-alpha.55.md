# TarnVPN 1.14.0-alpha.55

Исправлена совместимость с QR-подписками olcRTC от Oleglog/Olcrtc_manager.

## Что изменено

- добавлен legacy olcRTC runtime для manager handshake v1;
- `client_id`, DNS, keepalive и ключ из QR передаются в runtime без изменений;
- сохранён импорт `olcrtc://` и QR-кнопка в диалоге добавления сервера;
- APK-код увеличен до 707 для обновления поверх alpha.54.

## Проверка

- Go AAR собран для `arm`, `arm64`, `386`, `amd64`;
- Android unit-тесты, Spotless и release APK packaging проходят;
- APK подписан штатным TarnVPN release-сертификатом.

Живое подключение к конкретному серверу требует проверки на физическом
устройстве; ADB-устройство в окружении сборки не обнаружено.
