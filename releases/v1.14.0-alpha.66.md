# TarnVPN 1.14.0-alpha.66

Локальная сборка, сохраняющая исправления recovery из alpha.65 и прежние повторные уведомления сетевого интерфейса. Не опубликована.

- Смена сети во время выполняющегося recovery не теряется; быстрые переходы объединяются в один последующий reset.
- Отмена recovery не теряет первый handover или wake новой сессии.
- Сохранены прежние повторные уведомления интерфейса: native callback не подтверждает принятие интерфейса и может завершиться после ошибки поиска без исключения Android-клиенту.
- Сетевая ссылка публикуется между потоками через `@Volatile`.

Обе Android unit-test-варианты: 255 тестов, без ошибок и пропусков. Scoped Spotless, оба release APK с lintVital, подписи v1/v2/v3, package/version/minSdk и прежний сертификат проверены. Восемь native payloads совпадают с alpha.64.

`app.tarnvpn`, версия `1.14.0-alpha.66`, code `718`, universal minSdk 23 и legacy minSdk 21. Телефон не подключён: установка, sleep/handover и ChatGPT Work на устройстве не проверены.

Пользовательское падение скорости на alpha.65 устранено настройкой конфига. Регрессия пропускной способности клиента не установлена; эта сборка не объявляется исправлением скорости и не требуется для устранения уже решённой проблемы конфига.
