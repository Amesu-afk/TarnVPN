# TarnVPN 1.14.0-alpha.67 — кандидат восстановления XHTTP

Локальная сборка для проверки повторных подгрузок длинных YouTube Shorts на TestMiami-Test, Wi-Fi, без блокировки экрана.

При таймауте заменяется только отказавший элемент XHTTP-пула. Исправные текущие соседи сохраняются, включая соединения с паузами передачи. Поздние и одновременные ошибки старого элемента не сбрасывают его преемника; отказы разных элементов обрабатываются независимо. Полный сброс сети по-прежнему закрывает все старые соединения.

В журнале точечная замена отмечается `replaced one timed-out member`, счётчик — `member-refreshes`. Размер пула и таймауты 10/15 секунд сохранены. Android recovery из alpha.66 включён.

Кандидат устраняет подтверждённое локальным HTTP/2-тестом сопутствующее закрытие исправных соединений. Причина первого таймаута на сервере пользователя и исчезновение подгрузок на телефоне пока не подтверждены. Публикация не выполнялась.

Для проверки установить поверх предыдущей версии, оставить тот же профиль и Wi-Fi, посмотреть длинные Shorts 10–15 минут. При повторных подгрузках сохранить журнал. Отдельно проверить возвращение после блокировки экрана и смену Wi-Fi/мобильной сети.
