# TarnVPN 1.14.0-alpha.61

Проверочная сборка для восстановления соединения olcRTC после подключения.

## Изменения

- Перезагрузка sing-box с тем же olcRTC URI больше не останавливает работающий
  WebRTC-клиент и не запускает повторный handshake. Смена профиля и полный stop
  по-прежнему закрывают старый runtime.
- VERSION_CODE увеличен до 713.

## Проверка

- Unit-тесты lifecycle для обычной и Android 5-сборки прошли.
- Стабильность Telemost на телефоне ещё требует повторной проверки. Причина
  `read welcome: handshake: read body: timeout` без серверного журнала не
  установлена; исправлен подтверждённый риск ненужного перезапуска клиента.
