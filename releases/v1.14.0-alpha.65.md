# TarnVPN 1.14.0-alpha.65

Подготовленная локальная сборка с исправлением восстановления при смене Wi-Fi ↔ мобильная сеть. Публикация релиза ещё не выполнена.

## Изменения с alpha.64

- Смена сети во время уже выполняющегося восстановления больше не теряется: она сохраняется и обрабатывается после текущего сброса. Несколько быстрых событий объединяются.
- Исправлена потеря первого события сети или пробуждения после отмены предыдущего recovery.
- Сетевой monitor завершает повторные попытки после первого успешного уведомления ядра, вместо десяти одинаковых уведомлений.
- Ссылка на текущую сеть публикуется для других потоков через `@Volatile`.

## Проверка

- Четыре новые регрессии воспроизвели дефект на старом коде.
- После исправления 255 Android unit-тестов прошли на main и legacy; форматирование изменённых файлов прошло.
- Обе release-сборки и lint прошли, ошибок lint нет; существующие предупреждения отражены в отчёте.
- Подписи v1/v2/v3, package/version/minSdk и совпадение сертификата с alpha.64 проверены.
- Восемь нативных библиотек в APK совпадают с alpha.64. Изменения относятся к Android recovery; native ядро и протокол XHTTP не менялись.

## Установка и ограничения

Два универсальных APK: Android 6+ (minSdk 23) и legacy Android 5+ (minSdk 21). Версия `1.14.0-alpha.65`, code `717`, package `app.tarnvpn`, прежний сертификат подписи.

Телефон не подключён. Установка, реальные переходы между сетями, поведение ChatGPT Work после сна/фона и батарея требуют проверки на устройстве. Исправление подтверждено для recovery-кода; причина каждого зависания Work ещё не установлена. Для восстановления после сна должна быть включена настройка «Восстанавливать после сна и смены сети».
