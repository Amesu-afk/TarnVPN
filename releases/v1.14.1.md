Относительно **v1.14.0** (alpha.96). Первый релиз на тегированном ядре: CI теперь резолвит тег ядра в commit и проверяет версию Go и ядра внутри собранного AAR.

## Ядро

- `libbox` пересобран из тега **v1.14.4-lx.34** (commit `7f1909930`), Go **1.26.11**.
- Обновлены зависимости ядра: `x/crypto`, `x/net`, `grpc`, `brotli`, `compress`, `chi`, `dhcp` — свежие security-исправления транспортов и HTTP-стека.
- `govulncheck` (source и binary) — чистый. Ядро в релизе больше не «обезличенный» снапшот: тег → commit → проверка версии внутри AAR.

## Безопасность приложения

- Маскировка конфигов в crash/OOM-отчётах расширена: больше полей кредов и адресов вычищается до записи отчёта (покрытие проверяется unit-тестами).
- Открытие ссылок из внешних интентов (`Action.OPEN_URL`) — только по HTTPS и с явным подтверждением пользователя; scheme-подмены отклоняются.
- Харденинг сервисов: watchdog, отчёты о сбоях и обёртка платформенного интерфейса сужены до необходимого; из манифеста убраны лишние экспортируемые точки.

## VPN и сеть

- Include-список приложений для туннеля валидируется: пустой список установленных приложений больше не приводит к невалидной конфигурации — состояние отслеживается явно, покрытие тестами.
- Загрузка подписок, HTTP-клиент и импорт VLESS-конфигураций усилены: stricter-парсинг, обработка ошибок и таймаутов, покрытие unit-тестами.
- Подписки в legacy-плоском формате `ss://метод:пароль@host` больше не ломают профиль ошибкой «unknown method» (#14): парсер отличает plain-запись от base64 и не пропускает мусор в шифр.
- Большие подписки (тысячи серверов) теперь импортируются: берутся первые 128 серверов с явным уведомлением «пропущено N из M», вместо отказа в импорте из-за лимита символов (#14).
- Декодер QRS-кодов (перенос конфигов через QR) устойчив к повреждённым данным; обработка share/import-интенсов с тестами.

## Прочее

- Обновления гео-данных и экрана серверов, локализация: фарси, упрощённый и традиционный китайский.

## Проверено

- 361 Android unit-тест — зелёные; lint — 0 ошибок; Spotless — зелёный.
- Сборка протестирована на устройстве: ядро 1.14.4-lx.34 / go1.26.11 внутри AAR.

Профили обновлять не нужно: конфиг пересобирается из исходной ссылки при каждом подключении.

## English

First release on a tagged core: CI resolves the core tag to a commit and verifies the Go and core versions inside the built AAR. Core rebuilt from v1.14.4-lx.34 (Go 1.26.11) with updated x/crypto, x/net, grpc, brotli, compress, chi and dhcp; govulncheck clean. App hardening: wider config redaction in crash reports, HTTPS-only open-URL intents with user confirmation, trimmed exported components. VPN: validated per-app include list, hardened subscription fetching, HTTP client and VLESS import, robust QR-code (QRS) decoding. Subscription fixes (#14): legacy plain `ss://method:password@host` links no longer produce an "unknown method" profile failure, and oversized subscriptions now import their first 128 servers with a visible notice instead of being refused. fa/zh locales updated. 366 unit tests, lint and Spotless green; device-tested.
