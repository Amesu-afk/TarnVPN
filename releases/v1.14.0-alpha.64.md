# TarnVPN 1.14.0-alpha.64

Предварительная версия с исправлениями восстановления XHTTP после сна телефона.

## Изменения после alpha.63

- Настройка «Восстанавливать после сна и смены сети» теперь учитывает пробуждение после 60 секунд с выключенным экраном, а также deep/light idle. Восстановление запускается и на той же Wi-Fi сети.
- Восстановление сбрасывает сетевые соединения и DNS ядра, сохраняя VPN-интерфейс. Повторные события объединяются; полный reload ядра больше не используется для этого пути.
- XHTTP закрывает зависшие физические сокеты, в том числе оставшиеся после замены слотов пула. Закрытие upload pipe освобождает заблокированные HTTP/2 чтения и записи; поздние соединения старого поколения закрываются.
- DoH-запрос получает одну повторную попытку, если ошибка совпала с фактической заменой транспорта. Исходный таймаут запроса сохраняется.
- В logcat добавлены причина и длительность восстановления для диагностики задержек.

## Установка

Для Android 6+ нужен `TarnVPN-1.14.0-alpha.64-universal.apk`; для Android 5.0–5.1 — APK с `legacy-android-5` в имени. Код версии повышен с 715 до 716. Для обновления через приложение выберите канал «Бета».

## Проверка и ограничения

Прошли 243 Android unit-теста: 128 для основной сборки и 115 для legacy, без ошибок и пропусков. Прошли Go-тесты XHTTP, DNS и route с `with_xhttp` и без тега, `go vet` затронутых пакетов и проверка формата изменённых Kotlin-файлов. Оба release APK собраны с R8 и lintVital; полный Android lint обоих вариантов также прошёл. Подтверждены package `app.tarnvpn`, код версии 716, общий сертификат TarnVPN и соответствие всех восьми native-библиотек исходным AAR после штатного strip. Основная сборка требует API 23, legacy — API 21.

Физический телефон не подключён: установка поверх предыдущей версии, Telegram/YouTube после сна, переход Wi-Fi ↔ мобильная сеть и расход батареи ещё не проверены. Это исправление известных ошибок клиента, а не гарантия отсутствия любой задержки на конкретной сети. Сетевой reset прерывает текущие прикладные соединения; приложения должны подключиться снова. Потоковые upload-запросы автоматически не воспроизводятся. Handshake-бюджеты XHTTP 10/15 секунд сохранены; без события восстановления молчащий warm stream-one может ждать свой таймаут.

Исходники встроенного ядра: [Amesu-afk/sing-box-lx@038a715fe](https://github.com/Amesu-afk/sing-box-lx/commit/038a715fe1bc5b9a553cdea62000ffa2777da978), база `v1.14.0-lx.24`.

## English

This prerelease fixes client recovery after phone sleep: wake events on the same Wi-Fi now reset core network/DNS connections without recreating the VPN interface; XHTTP owns and closes sockets across pool replacement, closes upload pipes, and rejects late dials from the old network generation. DoH retries once only across an observed transport reset within the caller's original deadline.

The physical-phone update, Telegram/YouTube after sleep, Wi-Fi/mobile handover, and battery impact remain unverified. Existing application connections are interrupted by a network reset. Streaming uploads are not replayed, and the XHTTP handshake budgets remain unchanged. Select the Beta update track to receive this release.
