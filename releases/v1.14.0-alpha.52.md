# TarnVPN 1.14.0-alpha.52

Исправлена совместимость с VLESS + XHTTP + REALITY-ссылками, экспортированными
3x-ui 3.8.0 на Xray v26.9.9.

## Что исправлено

- Импортируются новые XHTTP-поля `sessionIDPlacement`, `sessionIDKey`,
  `sessionIDTable` и `sessionIDLength` из ссылки и блока `extra`.
- Канонические имена полей Xray переводятся во внутренний формат TarnVPN без
  потери значений и диапазонов.
- Сохраняется VLESS `encryption`, включая актуальные ML-KEM/X25519 параметры.
- `xtls-rprx-vision` сохраняется для поддерживаемой комбинации XHTTP + VLESS
  encryption; для несовместимых потоковых транспортов flow по-прежнему очищается.
- Ранее импортированные профили автоматически пересобираются после обновления,
  поэтому повторно добавлять ссылку обычно не требуется.
- REALITY ClientHello теперь содержит обязательный для Xray v26.9.8+
  `X25519MLKEM768` перед запасным `X25519`.
- Fingerprint `firefox` получает настоящую ML-KEM key pair до построения
  ClientHello; Chrome и другие TLS 1.3 fingerprints не получают дубликаты групп.
- Сохранён обычный `X25519`, который используется REALITY-аутентификацией и
  обеспечивает совместимость со старыми серверами.

## Проверка

- VLESS + XHTTP + REALITY из 3x-ui 3.8.0 / Xray v26.9.9 проверен на физическом
  устройстве: подключение и открытие сайтов работают.
- 181 Android unit-тест пройден без ошибок.
- Go-тесты REALITY/XHTTP, Android lint и обе release-сборки прошли.
