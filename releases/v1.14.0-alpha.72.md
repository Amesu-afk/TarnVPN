# TarnVPN 1.14.0-alpha.72

Небольшое предварительное обновление для Android: исправлен импорт некоторых подписок и упрощено управление их серверами.

## Что изменилось

- **Импорт подписок:** если провайдер вместо списка ссылок возвращает полную JSON-конфигурацию sing-box, приложение повторно запрашивает у него совместимый список серверов. Если провайдер его не предоставляет, показывается понятное сообщение. В исходной проблемной подписке были распознаны все 16 ссылок; пользователь подтвердил, что серверы добавились в предыдущей тестовой сборке.
- **Удаление подписки:** на экране «Серверы» появился заметный переход в «Подписки», а в карточке подписки — подписанная кнопка удаления. После подтверждения удаляются подписка и все относящиеся к ней серверы. Диалог показывает их число и предупреждает об отключении VPN, если среди них выбранный сервер.
- **Надёжность удаления:** если во время удаления закрыть экран, приложение завершит начатое удаление данных подписки. При выборе профилей учитывается их принадлежность к конкретной подписке.

## Установка и ограничения

Выберите universal APK для Android 6+ или legacy universal для Android 5. Для обновления из приложения выберите канал **«Бета»**. Нужен свой сервер или подписка.

Совместимый список ссылок импортируется как отдельные серверы; собственные правила маршрутизации полного JSON-конфига при этом не переносятся. Результат зависит от форматов, которые предоставляет провайдер.

Прошли 140 основных и 127 legacy unit-тестов, включая проверку выбора профилей конкретной подписки, обе release-сборки и lintVital. Подписи APK совпадают с alpha.70. Новое удаление подписки, обновление поверх старой версии и Android 5 на физическом устройстве отдельно не проверялись.

Crash/OOM-отчёты всё ещё могут содержать конфигурацию с секретами во внешнем каталоге приложения. Ограничение alpha.70 с массовым удалением при частичном, но полностью валидном ответе подписки также остаётся.

## English

This prerelease improves importing subscriptions from providers that return sing-box JSON when a compatible share-link response is available. Subscription management is easier to find, with a labelled action to remove a subscription and its associated servers. The provider's JSON routing rules are not imported. Both Android variants passed unit tests and release builds; physical-device validation of the new deletion flow is pending.
