Относительно **alpha.89**. Это единый релиз, в который вошло всё накопившееся после alpha.89, включая пересобранный `libbox` (ядро sing-box-lx) с новыми настройками XHTTP.

## Что изменилось с alpha.89

- **Туннель переживает смерть процесса.** `START_STICKY` плюс watchdog на WorkManager: если процесс упал или система его выгрузила, туннель поднимается сам, и об этом всегда приходит уведомление — молча трафик без VPN не остаётся. При ручном отключении туннель не оживает.
- **Автозапуск после перезагрузки** — отдельный переключатель в «Защите»; раньше восстановление после ребута было безусловным.
- **Онбординг Always-on VPN.** После первого подключения приложение один раз предлагает включить системный lockdown («Блокировать соединения без VPN») и открывает нужную страницу настроек.
- **Свои запросы — через туннель.** Проверка обновлений, подписки и fetch профилей при активном VPN идут через loopback SOCKS-инбаунд ядра с обязательной авторизацией; доменное имя резолвится внутри туннеля, а не системным DNS.
- **Приватность на диске.** `cache.db` (история DNS) исключён из облачных бэкапов и переноса на новое устройство; креды в crash/OOM-отчётах маскируются; User-Agent больше не содержит версию, версию ядра и локаль; FileProvider сужен до реально расшариваемых каталогов.
- **Настройки.** Пул XHTTP (4/8/16 соединений), мультиплексирование (mux) для TCP-серверов, экспорт сервера ссылкой и QR, интервал автообновления подписок (6/12/24/48 ч).
- **Ядро.** XHTTP `xmux` (ширина пула соединений) и `download_settings` (асимметричный download: отдельные Host/path/headers для загрузки — под CDN-схемы). `libbox.aar` пересобран из текущего дерева ядра.
- **Маршруты и per-app.** VPN-приложение исключено из своего туннеля во всех режимах; пустой include-список откатывается на глобальный; браузеры добавляются автоматически; endpoint исключён из TUN-маршрута, web-страницы остаются в туннеле, YouTube сохраняет QUIC.
- **Стек TUN** (gVisor / mixed / system) в «Лаборатории соединения».

## Импорт конфигураций

- WireGuard/AmneziaWG: `.conf`-файлы и `vpn://`-ссылки, включая WARP и Cloudflare IP-edge профили.

## Проверено

- Android unit-тесты (main и legacy) — зелёные.
- Go-тесты изменённых пакетов ядра (XHTTP) — зелёные.
- Сборка протестирована на устройстве.

Перед обновлять профили не нужно: конфиг пересобирается из исходной ссылки при каждом подключении.

## English

Squashed release on top of alpha.89: tunnel watchdog and START_STICKY recovery, boot autostart toggle, one-time Android lockdown onboarding, the app's own traffic routed back through the tunnel (loopback SOCKS, remote DNS), privacy fixes (backup-excluded DNS cache, redacted report configs, User-Agent without build/locale, narrower FileProvider), XHTTP pool width and download_settings in the rebuilt core, mux for TCP outbounds, server export with QR, subscription refresh interval. Unit tests pass; device-tested.
