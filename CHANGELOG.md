# Changelog

Один раздел на релиз; подробные заметки и ограничения — в `releases/<tag>.md` и
на странице релиза GitHub. Здесь — короткая история для тех, кто читает
репозиторий, а не вкладку Releases.

## 1.14.0-alpha.96 — 2026-11-16

**Туннель**
- Туннель переживает смерть процесса: `START_STICKY` + watchdog на WorkManager,
  уведомление о каждом восстановлении; ручное отключение не отменяется.
- Автозапуск после перезагрузки — отдельный переключатель.
- Разовый онбординг Android Always-on VPN / «Блокировать соединения без VPN».

**Приватность**
- `cache.db` (история DNS) исключён из облачных бэкапов и переноса.
- Креды в сохранённых crash/OOM-отчётах маскируются; User-Agent без версии,
  ядра и локали.
- FileProvider сужен до реально расшариваемых каталогов.
- Собственные запросы приложения идут через туннель (loopback SOCKS с
  авторизацией, DNS резолвится внутри туннеля).

**Настройки**
- Пул XHTTP 4/8/16 соединений (`xmux.max_connections`), mux для TCP-серверов.
- Экспорт сервера исходной ссылкой и QR.
- Интервал автообновления подписок 6/12/24/48 часов.
- Стек TUN: gVisor / mixed / system.

**Ядро**
- XHTTP `xmux` (ширина пула) и `download_settings` (асимметричный download).
- `libbox.aar` пересобран из тега `tarnvpn-v1.14.0-alpha.96`.

**Инфраструктура**
- CI: gitleaks по истории + сборка ядра из тега, unit-тесты, debug-сборка.
- `SECURITY.md` с приватными GitHub Advisories; чек-лист публикаций.

## 1.14.0-alpha.89 — 2026-11-12

- Импорт WireGuard/AmneziaWG из `.conf` и `vpn://` (включая WARP и Cloudflare
  IP-edge профили).
- Per-app и маршруты: VPN-приложение вне своего туннеля во всех режимах, пустой
  include-список откатывается на глобальный, endpoint исключён из TUN-маршрута.
- YouTube/QUIC: web-страницы остаются в туннеле, QUIC управляется политикой.
- Надёжность: регенерация конфига из `.vless` при каждом подключении,
  `CONFIG_GENERATION` 12; таймауты XHTTP.
- Ядро: AWG 3.0/3.1 (защита заголовков, паддинг, ranged timings), правки
  tlsfragment/MASQUE/sing-tun.

История до alpha.89 — в [Releases](https://github.com/Amesu-afk/TarnVPN/releases).
